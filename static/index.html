How this model works

Base instruct models produce unstructured prose when asked to screen a resume — not something you can pipe into an ATS pipeline. This model was fine-tuned with LoRA (r=16, alpha=32) on 800 resume → structured-verdict examples so JSON output is the model's default behavior, not something coaxed out with prompting. The model's raw skill list and score are validated against the actual resume text before display — any skill it claims that isn't really in the resume is filtered out, and the score/verdict are recomputed from the validated match ratio so they can't contradict each other.
